# 常用工具

### 1. 在线HTTP请求
[https://request.perk-net.com/http](https://request.perk-net.com/http)

模拟程序发送HTTP请求，方便在线调用pushplus接口来验证结果。

### 2. HTTP请求接收地址
[http://request.perk-net.com/](http://request.perk-net.com/)

生成临时的HTTP地址，实时查询收到的请求报文内容，方便排查程序代码发送请求报文是否正确。

### 3. Json格式化
[https://www.bejson.com/](https://www.bejson.com/)

格式化Json数据内容，校验Json数据是否有错，

### 4. url编码解码
[https://toolb.cn/urlencode](https://toolb.cn/urlencode)

pushplus接口需要将带有中文的url地址编码后发送请求。

### 5. 在线markdown编辑器
[http://tool.mkblog.cn/markdown/](http://tool.mkblog.cn/markdown/)

编辑markdown格式文本，实时查看效果。
