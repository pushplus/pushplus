# APP上没有通知弹框

1. 确认下使用的手机，pushplus的APP通知渠道适配了国内主流的厂商(华为、荣耀、小米、OPPO、vivo)，同时也适配了安卓原生的FCM渠道和iOS渠道。如果手机是海外品牌或国际版，通知是走安卓原生的FCM渠道的，需要手机网络翻墙。

2. 确认下应用的通知权限是否开启。安卓手机需要在手机的“设置”->“通知管理”中找到“pushplus”，允许通知。并且在“通知类别”中也启用“允许通知”。苹果手机操作类似。

![](../images/1.png)

3. 只有“发送渠道(channel参数)”是App的消息，才会在手机APP中有通知。其他渠道(微信服务号、短信、邮件、语音、webhook等)的消息，请到其他渠道中查看。

![](../images/2.png)

4. 如确认了以上情况，还有问题的可以加QQ反馈。
