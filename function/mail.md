# 发邮件来推送消息的使用说明

## 引言
&emsp;&emsp;发送邮件推送消息提供了一种无需调用 HTTP 接口的推送方式：向专属邮箱发送一封邮件，即可触发 pushplus 消息推送。邮件主题对应消息标题（`title`），邮件正文对应消息内容（`content`），发送渠道使用该令牌对应的默认发送渠道。\
&emsp;&emsp;token 支持**用户令牌**或**消息令牌**。收件人统一为 `{token}@yp9.cn`；一对多、好友消息通过**抄送（Cc）**指定目标。邮箱域名固定为 `yp9.cn`，非该域名或无效 token 的邮件将被忽略。

## 邮箱填写规则

| 类型 | 填写位置 | 格式 | 说明 |
| --- | --- | --- | --- |
| 收件人 | To | `{token}@yp9.cn` | 固定为你的用户令牌或消息令牌 |
| 一对一 | 仅收件人 | 不填抄送 | 推送给自己 |
| 一对多 | 抄送 Cc | `{群组编码}@yp9.cn` | 支持多个 |
| 好友消息 | 抄送 Cc | `{好友令牌}@yp9.cn` | 支持多个 |


示例：

```
# 一对一
收件人：5813c18bb0fa462789028312dae30224@yp9.cn

# 一对多（可抄送多个群组）
收件人：5813c18bb0fa462789028312dae30224@yp9.cn
抄送：mytopic@yp9.cn, alert@yp9.cn

# 好友消息（可抄送多个好友）
收件人：5813c18bb0fa462789028312dae30224@yp9.cn
抄送：a1b2c3d4e5f6478890a1b2c3d4e5f647@yp9.cn, b2c3d4e5f6478890a1b2c3d4e5f647a1@yp9.cn
```

## 使用步骤
1. 登录 [pushplus 官网](https://www.pushplus.plus)，在「发送消息」相关页面的「调用方式」中查看自己的专属收件邮箱。
2. 使用任意邮箱客户端，将收件人设为 `{token}@yp9.cn`。
3. 如需一对多或好友消息，在抄送中按上表填写 `群组编码@yp9.cn` 或 `好友令牌@yp9.cn`。
4. 填写邮件主题（推送标题）和正文（推送内容，支持 HTML 富文本）后发送。
5. 发送成功后，pushplus 会按该令牌的默认渠道完成推送，可在「消息列表」中查看结果。

## 注意事项
1. 收件人、抄送地址均须使用 `@yp9.cn` 域名。
2. 一对多请先创建群组并确认编码正确；好友消息请先添加好友并使用正确好友令牌。
3. 同一封邮件抄送中可同时包含群组编码与好友令牌，系统会分成两组并分别推送。
4. 邮件推送同样受 [发送消息接口限制](../help/limit.md) 约束，请控制发送频率。
5. 推送请求成功并不代表渠道一定投递成功，请根据消息流水号查询最终发送结果。

## 与接口推送的关系
&emsp;&emsp;邮件推送与 [消息接口](../guide/api.md) 最终走同一套推送逻辑，适合不便编写代码、或希望用现有邮件告警/脚本触发推送的场景。若需要更灵活的参数控制（如指定 `channel`、`template`、`callbackUrl` 等），仍推荐使用官方 [pushplus SDK](../guide/sdk.md) 或 HTTP 接口。\
